# Tselora

**Open-source execution intelligence for AI agents.**

Tselora reconstructs what an existing agent actually did into a deterministic execution model. It is not an agent framework or orchestrator. It sits beside agents you already run.

- Install: `pip install tselora` (Python 3.12+)
- Docs, examples, and the demo GIF: [github.com/Tselora/Tselora](https://github.com/Tselora/Tselora)
- Package: [pypi.org/project/tselora](https://pypi.org/project/tselora/)

The public repository is the place for quickstart, adapters, REST, Experience, comparison, and Learn (exact structure-fingerprint cohorts). Implementation ships on PyPI.
